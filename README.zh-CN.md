# Bleep Studio 游戏音效工作台

**在浏览器里，给你的游戏配齐一整套声音。**

[English](README.md)

无需后端服务器、账号、API Key 或付费服务。所有声音都在浏览器本地合成，无需上传任何文件。

## 开始使用

直接用最新版浏览器打开 **index.html**。完整网页无需安装依赖、无需构建。

也可以在项目目录运行：

    npm start

访问 http://127.0.0.1:4173。Node.js 18+ 只用于这个可选的本地预览和测试，不是网站运行条件。

## 已有功能

- **三套风格：**像素街机、可爱经营、科幻电子，每套 18 种音效。
- **常用事件：**金币、跳跃、点击、悬停、确认、取消、伤害、爆炸、激光、能量提升、升级、胜利、结束、掠过、通知、解锁、治疗、错误。
- **独立调音：**每套风格的每个音效都有自己的音高、时长、明亮度、力度、空间感和随机种子。
- **实际波形：**调音台显示渲染后的音频波形。卡片上的迷你线条是装饰性的声音图案。
- **收藏与搜索：**支持中文、英文搜索；参数和收藏仅保存在当前浏览器。
- **交互场景：**让小方块跳跃、收金币、受伤和获胜，试听声音搭配。
- **单个与整套导出：**44.1 / 48 kHz、单声道、16-bit PCM WAV，整套 ZIP 附参数清单和引擎接入说明。
- **中英文界面、键盘操作、手机布局。**

试听音量与静音不影响导出。整套导出包含当前风格的全部 18 个音效，使用点击导出时的参数快照，不受搜索和收藏筛选影响。

## 免费上线

把本目录作为 GitHub 仓库根目录推送到 **main** 分支。在 **Settings → Pages → Build and deployment** 里选择 **GitHub Actions**。已包含测试和发布工作流，部署时只上传网页必要文件。

无需购买服务器或域名。也可将 index.html、style.css、app.js、engine.js、icon.svg 放在其他静态托管服务上。当前交付是本地版本，是否已发布请以实际仓库及网址为准。

## 使用权

源码采用 MIT 协议。生成的音频可以用于个人及商业游戏，无需署名；全部使用原创程序化配方，没有第三方采样素材。

## 使用范围

这是一套程序化合成工具，适合像素、休闲、界面和科幻效果。目前不包含自然语言生成、真实乐器录音、云端账号和跨设备同步。浏览器清理本地数据后，设置可能丢失。

相同版本下，用 manifest.json 中的风格和参数可以通过 Bleep.render API 复现声音。浏览器及版本差异可能带来微小数值差别。详细 API 和部署说明见英文 README。

## 检查

运行 **npm test** 进行配方、WAV 编码、CRC32 和 ZIP 格式测试。通过本地预览打开 **/tests/browser.html** 可以运行实际浏览器音频渲染检查。实测记录见 VALIDATION.md。
